# 📚 Student Assignment Tracker

A simple web application that helps students manage their assignments, deadlines, priorities, and completion status.

## 🎯 Project Objective

Students often have multiple assignments from different subjects and can easily lose track of deadlines.

The goal of this project is to provide a simple dashboard where students can:

- Add assignments
- Track deadlines
- Set priorities
- Mark assignments as completed
- Delete assignments
- Search assignments
- View assignment statistics

## 🚀 Features

- Add new assignments
- Set assignment priority
- Track pending and completed assignments
- View assignments due soon
- Search assignments
- Delete assignments
- Responsive design
